## 🚀 &nbsp; Featured Projects

### 🎙️ AI-Powered Voice Recruiter Agent
`Next.js` `TypeScript` `Vapi AI` `Groq` `Prisma` `Stripe`

A multilingual AI interview platform with real-time voice interviews in **English, Hindi, and Urdu**, automated candidate evaluation, and structured AI feedback. Includes Stripe-based credit billing, payment verification, and interview integrity checks such as browser tab-switch detection.

[![GitHub](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/M-SuhaibGM/AI_RECRUTER) [![Live](https://img.shields.io/badge/Live-Demo-7C3AED?style=flat-square&logo=vercel&logoColor=white)](https://ai-recruter-five.vercel.app)

### 🎲 Ludo: Real-Time Multiplayer Game
`Next.js` `TypeScript` `Node.js` `Socket.IO`

A real-time multiplayer Ludo game with private rooms, reconnection support, live chat, and AI opponents at three difficulty levels. Uses server-authoritative game logic, move validation, turn management, and session tokens to protect against invalid moves.

[![GitHub](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/M-SuhaibGM/Ludo-Real-time-Backend) [![Live](https://img.shields.io/badge/Live-Demo-7C3AED?style=flat-square&logo=vercel&logoColor=white)](https://ludo-real-time-frontend.vercel.app)

### 📊 AI-Powered Presentation Generator
`Next.js` `TypeScript` `LLM Orchestration` `Inngest` `Zod`

Converts text prompts and meeting notes into structured slide decks using LLM orchestration. Uses asynchronous generation workflows with Inngest, job-status polling, and Zod-based validation to handle inconsistent AI outputs.

[![GitHub](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/M-SuhaibGM/text-to-ppt)
